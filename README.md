# Hackathon Stockline — Team 09 · Crèmerie des Aravis

Team layer on top of Stockline's voice ERP kit. **The kit itself is pushed here once `make setup` works** (see
`docs/TEAM_OPS.md` §0); after that, this README is replaced by the kit's README.

- `CLAUDE.md` — rules for every Claude session (read with the kit's `AGENTS.md`)
- `DECISIONS.md` — problem, choices, measurements (read by the jury)
- `scenarios/` — scripted calls + `run.py` (timings and checks over the kit's voice WebSocket)
- `apps/ai/app/agent/speak_fr.py` — numbers, prices, quantities, dates → spoken French
- `docs/` — team ops, domain playbook, pitch & demo, current state
